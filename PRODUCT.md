# Product

## Register

brand

## Users

Recruiters, hiring managers, and tech leads (KSA, India, remote) screening Emad Mohammed Habibi for backend-leaning full-stack roles (.NET / ASP.NET Core + React). They arrive from his resume, LinkedIn, or GitHub and decide in under a minute whether to shortlist him.

## Product Purpose

A single-page portfolio that converts resume screening into interviews. It must prove production credibility (fault-tolerant .NET services processing 20,000+ orders/day at Anan Alsamaa IT Solutions) and never contradict the resume: same dates, same numbers, same stack.

## Brand Personality

Precise, engineered, quietly confident. Reads like a well-built internal tool, not a marketing page.

## Anti-references

- Generic AI portfolio slop: purple-to-pink gradient text, centered serif titles with gradient underlines, dozens of purple pill badges, typing-effect overload.
- Template Dribbble portfolios with stock illustrations and vague "passionate developer" copy.

## Design Principles

- Evidence over adjectives: real order volumes, real stacks, real dates. No buzzwords.
- One accent (violet), used sparingly; monochrome carries the page.
- Mono type is the data voice: dates, stats, tech tags, section eyebrows.
- Resume parity: content on the site is sourced from the current CV, nothing invented.

## Accessibility & Inclusion

WCAG AA contrast, visible keyboard focus rings, skip-to-content link, `prefers-reduced-motion` honored everywhere.
